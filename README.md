# brand-style-research

品牌风格研究规范：把"研究一个汽车品牌"变成固定可复用流程，以**品牌为主体**产出全景文档。

## 这是什么

一个可复用的 AI Agent 技能（Skill），来自真实业务场景沉淀。适用于需要系统研究某个品牌（汽车/消费/科技均可）的风格、文化、表达体系、KOL 生态的场景。

## 解决的问题

研究一个品牌时常见问题：
- 素材散乱，不知道从哪收集
- 产出按"人物"分章，看不到品牌整体调性
- 只学了媒体二手解读，没吃透一手语料
- KOL 研究只学语言风格，没提炼深层内涵

## 核心方法论

1. **以品牌为主体**——按"身份/表达体系/文化内核/生态视角"四层组装，不按人分章
2. **只用一手原版资料**——官方文档、发布会实录、官方社媒全量，禁断章取义
3. **语言风格 vs 内容内涵分开学**——官方学风格，KOL 学内涵
4. **数据必须换算**——参数转用户价值（"省 X 小时"而非"功率 X kW"）
5. **引用有出处**——金句标注来源人物/场合

## 研究流程（6阶段）

| 阶段 | 目标 | 动作 | 产出 |
|------|------|------|------|
| S1 | 官方语料 | 官网/品牌文档/使命愿景 | 品牌身份表 |
| S2 | 创始人+高管表达 | 发布会实录/专访/用户沟通会 | 人物风格指纹 |
| S3 | 官方社媒 | 小红书/微博全量笔记 | 内容模板+固定短语库 |
| S4 | 品牌文化 | 品牌故事/仪式/危机范式 | 三观表+关键词宇宙 |
| S5 | 深度KOL生态 | 搜索候选→用户确认→深挖内涵 | KOL知识库 |
| S6 | 组装全景 | 五章结构文档 | 完整品牌全景文档 |

## 使用方式

将本仓库内容放入你的 Agent 技能目录：

- **Hermes**: `skills/` 目录
- **Claude**: `~/.claude/skills/`
- **其他 Agent**: 按对应 SKILL.md 格式

Agent 会在匹配触发条件时自动加载并使用。

## 交付物模板

```
# XX品牌风格全景
## 第一章 品牌身份与调性（是什么/性格拟人/三观）
## 第二章 品牌表达体系（三层：品牌层官方/人格层创始人/专业层高管）
## 第三章 品牌文化内核（故事/关键词宇宙/仪式符号/危机范式）
## 第四章 品牌生态视角（KOL如何解读）
## 第五章 应用指南（场景→指纹速查/写作红线/金句库）
## 附录A：内容模板详版
```

## 避坑清单

- 小红书官方号定位：按点赞排序+多关键词，别被个人用户淹没
- 批量拉正文会触发风控：间隔≥3s，分批（每批≤20）
- 视频笔记 desc 常为空：标题+互动数据也有价值
- KOL 纳入需用户确认，不擅自扩大范围

## 内容结构

- `SKILL.md` — 核心技能定义（触发条件、执行流程、避坑清单）
- `references/` — 可选参考文件
